
# Flying Gaze Photography

**Flying Gaze Photography Website and Android Platform**

A photography platform for managing client events, private photo galleries, photo selection, and digital albums.

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

You can start editing the homepage in `src/app/page.tsx`.

## Project Information

- Project: Flying Gaze Photography
- Platform: Web and Android
- Framework: Next.js
